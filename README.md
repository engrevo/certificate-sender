# مُرسِل شهادات الحضور · Certificate Sender

موقع (Flask) خفيف يخلي المنظّم يرفع **أي تصميم شهادة**، ويحدد بنفسه مكان كتابة الاسم بسحب مربع، ثم يولّد شهادة PDF لكل شخص في القائمة ويرسلها له على **واتساب من رقمك الشخصي**، أو تلقائيًا عن طريق WhatsApp API.

> Upload any certificate design → drag a box to where the name goes → generate a PDF per attendee → send each one on WhatsApp from your own number.

## المميزات

- **تحديد مكان الاسم بالسحب، مع معاينة فورية**: مربع تقدر تسحبه وتغيّر حجمه فوق الشهادة، والاسم يتحدث مباشرة وأنت تسحب، لأن المعاينة ترتسم في المتصفح بنفس الخطوط وبدون انتظار السيرفر. والموقع يتذكر آخر مكان حطيته فيه.
- **سرعة**: الصور الكبيرة تصغر في المتصفح قبل الرفع، والإرسال يشتغل على ٤ رسائل بنفس الوقت (`SEND_CONCURRENCY`).
- **دعم كامل للعربي**: تشكيل الحروف واتجاهها صح، والخط يصغر تلقائيًا للأسماء الطويلة. فيه خطان: Amiri وTajawal.
- **القائمة** تنقرأ من Excel أو CSV أو نص ملصوق، وأسماء الأعمدة تُكتشف بالعربي أو الإنجليزي.
- **توحيد أرقام الجوال**: الصيغ `05xxxxxxxx` و`5xxxxxxxx` و`+966…` و`00966…` والأرقام الهندية (٠٥٥…) كلها تتحول لصيغة واتساب.
- **الإرسال من رقمك (مجاني):** الموقع يجهّز لكل شخص شهادته برابط، ويفتح محادثته في واتساب والرسالة مكتوبة جاهزة، وأنت تضغط «إرسال» بس.
- **إرسال تلقائي (اختياري)** عن طريق WhatsApp Cloud API، مع شريط تقدّم وزر إيقاف وتقرير CSV.
- **تحميل كل الشهادات ZIP** بدون إرسال.
- **وضع تجربة** (`DRY_RUN=1`) يحفظ الملفات بدل ما يرسلها.
- **حماية بكلمة مرور** (`APP_PASSWORD`).

## التشغيل محليًا

```bash
git clone https://github.com/engrevo/certificate-sender.git
cd certificate-sender
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # وعدّل القيم
python run.py               # http://127.0.0.1:5000
```

أو استخدم Docker:

```bash
docker build -t certificate-sender .
docker run -p 8000:8000 --env-file .env certificate-sender
```

## الإرسال من رقمك الشخصي

1. ارفع الشهادة وحمّل قائمة الأسماء.
2. عدّل نص الرسالة لو تبي. `{name}` تتبدّل باسم الشخص، و`{link}` برابط شهادته.
3. اضغط **إرسال من رقمي على واتساب**. الموقع يجهّز الشهادات، وبعدها اضغط **افتح واتساب** لكل شخص: تنفتح محادثته والرسالة جاهزة، اضغط إرسال وارجع للي بعده.

> هذي الطريقة رسمية ومجانية، لأن واتساب نفسه هو اللي يفتح المحادثة وأنت اللي ترسل. والرقم لازم يكون محفوظ بصيغة صحيحة في القائمة.

### روابط دائمة للشهادات (Google Drive)

بدون إعداد، الشهادات تنحفظ على السيرفر. على خطة Render المجانية، السيرفر يمسح ملفاته لما ينام، فالروابط تخرب بعد فترة. عشان تبقى دائمة، احفظها في Google Drive حقك:

1. افتح [script.new](https://script.new) بحساب **Gmail شخصي** (حسابات الجامعة غالبًا تمنع مشاركة الملفات للعامة).
2. امسح الكود والصق محتوى [`apps_script/Code.gs`](apps_script/Code.gs)، وغيّر `SECRET` لكلمة سر طويلة من عندك.
3. **Deploy ← New deployment ← Web app**، واختر *Execute as: Me* و *Who has access: Anyone*، ووافق على الصلاحيات.
4. في Render ← الخدمة ← **Environment** أضف:
   - `DRIVE_SCRIPT_URL` = رابط الـ Web app (ينتهي بـ `/exec`)
   - `DRIVE_SCRIPT_SECRET` = نفس كلمة السر
5. احفظ، والموقع يعيد التشغيل لحاله. الشهادات بتنحفظ في مجلد «شهادات الحضور» في الدرايف حقك.

بعد الربط، رابط كل شخص يبقى رابط مِرسال (`/d/...`) ويفتح صفحة الشهادة بالمعاينة وزر التحميل، والموقع يجيب الملف من الدرايف وقت الفتح. فالروابط تشتغل حتى لو السيرفر نام أو انعاد تشغيله.

> **مهم:** لا تغيّر `DRIVE_SCRIPT_SECRET` بعد ما ترسل شهادات، لأن الروابط موقّعة فيه، ولو تغيّر تتعطل الروابط القديمة. ولا تحذف الملفات من مجلد الدرايف.

## إعداد واتساب API (اختياري — للإرسال التلقائي الكامل)

1. أنشئ تطبيق في [Meta for Developers](https://developers.facebook.com/) وأضف له منتج **WhatsApp**.
2. خذ **Phone number ID** و**Access token** (للاستخدام الدائم أنشئ System User token) وحطهم في `.env`.
3. أول رسالة لأي شخص لازم تكون **قالب رسالة معتمد** (Message Template). أنشئه من WhatsApp Manager بهذا الشكل:
   - **الاسم:** `attendance_certificate`
   - **الفئة:** Utility
   - **الترويسة (Header):** Document
   - **النص (Body):** `مرحبًا {{1}}، شكرًا لحضورك. مرفق لك شهادة الحضور.`
4. بعد ما ينعتمد، اضبط `WHATSAPP_TEMPLATE_NAME` و`WHATSAPP_TEMPLATE_LANG=ar`، وخلّ `DRY_RUN=0`.

> **ملاحظات:**
> - في رقم التجربة اللي تعطيك Meta، تقدر ترسل بس للأرقام اللي أضفتها في قائمة المستلمين المسموحين.
> - الرسائل خارج نافذة الـ 24 ساعة تنحسب عليك [حسب تسعير Meta](https://developers.facebook.com/docs/whatsapp/pricing).
> - `WHATSAPP_SEND_MODE=document` يرسل الملف مباشرة بدون قالب، ويشتغل بس مع شخص راسلك خلال آخر 24 ساعة.

## نصائح للمنظّم

- خلّ مكان الاسم **فاضي** في التصميم (Canva أو Figma أو غيرها)، وبعدين اسحب المربع عليه في الموقع. ارتفاع المربع يحدد حجم الخط.
- الشهادة ممكن تكون صورة أو PDF. إذا كانت PDF، الصفحة الأولى تتحول لصورة بدقة 200 DPI.
- **شكل ملف القائمة:**

  | الاسم | الجوال |
  |---|---|
  | عبدالله محمد العتيبي | 0551234567 |

## هيكل المشروع

```
app/
  renderer.py    # فتح القالب، مربع الاسم، كتابة الاسم بالعربي، تصدير PDF
  recipients.py  # قراءة القائمة وتوحيد الأرقام
  whatsapp.py    # عميل WhatsApp Cloud API
  storage.py     # حفظ الشهادات (السيرفر أو Google Drive) وروابطها
  jobs.py        # الإرسال في الخلفية + التقرير
  __init__.py    # مسارات Flask
  templates/ static/ fonts/
apps_script/     # سكربت Google Drive للروابط الدائمة
samples/         # قوالب تجريبية + make_samples.py
tests/           # pytest
```

## النشر

التطبيق يحتاج سيرفر Python دائم، لأن الإرسال يشتغل في الخلفية. يناسبه Render أو Railway أو Fly.io أو أي VPS باستخدام الـ Dockerfile. شغّله بعامل (worker) واحد، لأن حالة الإرسال محفوظة في الذاكرة، و**فعّل `APP_PASSWORD`** قبل ما تنشره.
